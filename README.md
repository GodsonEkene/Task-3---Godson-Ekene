# Sales Performance Analysis Using SQL

## Project Overview
This project analyzes sales performance, customer purchasing behavior, product performance, payment methods, and order status distribution using SQL.

The analysis focused on identifying:
- sales trends over time,
- customer purchasing behavior,
- best-selling products,
- payment method performance,
- and operational order distribution.

## Tools Used
- SQL Server
- Microsoft SQL Server Management Studio (SSMS)

## Dataset Features
The dataset included:
- OrderID
- Date
- customerID
- Product
- Quantity
- UnitPrice
- ShippngAddress
- PaymentMethod
- OrderStatus
- TrackingNumber
- ItemsinCart
- CouponCode
- ReferralSource
- TotalPrice

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- Common Table Expressions (CTE)
- YEAR() and MONTH() Functions
- ROUND()
- COUNT()
- SUM()

## Business Questions Answered
- How did sales perform over time?
- Which products generated the highest revenue?
- Which payment method generated the most revenue?
- How did quantity sold change over time?
- What was the distribution of order statuses?
- How did customer purchasing behavior change over time?

## Key Findings

### Revenue Trend
Revenue declined significantly in 2025 compared to previous years.

### Customer Purchasing Behaviour
Average quantity purchased per customer showed a moderate decline in 2025.

### Best-Selling Products
Laptop and Phone products generated the highest revenue.

### Payment Method Performance
Online payment generated the highest revenue among all payment methods.

### Order Status Distribution
Cancelled and returned orders remained relatively high compared to delivered orders.
